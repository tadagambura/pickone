# PickOne: Spec

**Rank in portfolio:** #2 of 15 (easiest → hardest) · **Difficulty:** Very easy

## One-liner

Can't decide? Add your options, spin the wheel, settle it.

## Problem / audience

- **Who it's for:** Friends picking a restaurant, couples choosing a film, teachers picking names, anyone stuck on a choice.
- **The problem it solves:** Small decisions waste time and cause arguments.

## MVP features (ship with only these)

1. Add options, spin a wheel, get a result
2. Weighted options (some more likely)
3. Coin flip and yes/no modes
4. Saved wheels (on device)
5. Share the result

## Not in MVP

- Premium wheel themes
- Unlimited saved decision sets
- Remove-after-pick mode for groups

## Monetisation

| Model | Detail |
|---|---|
| Free | Wheel + flips, with ads |
| Paid | Themes + unlimited saved wheels, one-off £1.99 |
| Ads | Banner + rewarded ad to unlock a theme |

Prices are starting points from the portfolio brief; test before committing.

## Platform & stack

- **Platform:** Web first, then Expo app.
- **Stack:** shared portfolio foundation (Expo, PostHog, RevenueCat, AdMob). See the portfolio roadmap.
- **Data:** Device only.

## Growth engine hooks

- **Shareable output:** Spin result screen and short spin recordings.
- **Content pillars:** Can't-decide situations; Date night / food picks; Classroom & party games

## Notes

Crowded category with low revenue per user. Worth it as a fast ship that reuses WorthIt's foundation and adds saved data.

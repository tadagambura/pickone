# PickOne

> **Merged into [AfterHours](https://github.com/tadagambura/afterhours).**

PickOne (decision wheel) is now the wheel inside AfterHours: spin for who goes first or the next deck. Standalone wheel apps are crowded and ad-funded, and Apple rejects near-identical simple apps (guideline 4.3), so it works better as a feature.

Decided in the November 2026 portfolio review, based on market research across Reddit, forums,
TikTok/YouTube trends and app-store reviews. This repo is kept for history and is no longer developed.
